# Theme Files

Below is a full list of everything that is included when you download the main files, along with a brief description of each item.

Please unpack the whole package after downloading it from Themeforest. On that extracted _**themeforest-fabish-shopify-theme.zip**_, You can find files like Documentation, Teenz.zip , Log.txt and Readme.txt. You need to install the file _**"fabish.zip".**_

* **fabish.zip** – This is the installable theme file you’ll need to install or upload.
* **Log.txt –** This file contains theme change/update log.
* **Readme.txt** – This file contains details about folder structure.
